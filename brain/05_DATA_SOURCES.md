# 05 — Data Sources

## Primary: User-Uploaded PDF Documents
- Types: Offer Letters, Contracts, NDAs, Rental Agreements, ToS
- Format: PDF only, max 20MB, max 50 pages

## Secondary: Gemini AI (Grounded Only)
- Used for language simplification, NOT for facts
- All factual claims trace back to uploaded document

## Privacy Rules
- Documents processed in-memory
- No permanent storage
- No PII logging
