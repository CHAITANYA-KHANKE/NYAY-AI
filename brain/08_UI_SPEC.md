# 08 — UI/UX Specification

## Design Principles
1. Clarity over cleverness
2. Trust through transparency (citations)
3. Minimal clicks (< 40 in demo)
4. Color-coded risk (Red/Yellow/Green)

## Colors
- Risk High: #EF4444 | Medium: #F59E0B | Low: #22C55E
- Primary: #2563EB | BG: #F8FAFC | Text: #1E293B

## Screens
1. Upload (drag-drop PDF)
2. Profile (role + concerns)
3. Dashboard (health score + clauses + chat)
4. Side-by-side verification

## Accessibility
- aria-labels on all buttons
- Contrast ratio >= 4.5:1
- Keyboard navigation
